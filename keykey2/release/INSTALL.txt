Yahoo! KeyKey 2 1.1.2 (x64)
===========================

Requirements
------------
- Windows 10/11 x64
- Administrator access for installation

Install
-------
1. Run KeyKey2-1.1.2-x64-Setup.exe.
2. Approve the UAC prompt.
3. Follow the English wizard. The default folder is:
   C:\Program Files\Yahoo!\KeyKey2
4. Restart WhatsApp (or any app that was already open).
5. Focus a text box and press Win+Space until
   "Yahoo! KeyKey 2" is selected.

If Yahoo! KeyKey 1.1.2535 is not installed, the installer installs the bundled
original KeyKey engine silently first. If KeyKey is already installed, it is
left untouched.

The installer also deploys KeyKey2.dll, install.ps1, uninstall.ps1, README.md,
and the license/notice files into the install folder. Running the Setup is the
supported path; the scripts are there for troubleshooting.

Troubleshooting
---------------
- Set KEYKEY2_DEBUG=1 for the target app, restart it, and read
  %TEMP%\KeyKey2.log.
- Restart ctfmon.exe / TextInputHost.exe (elevated) if the profile does not
  appear.
- Make sure KeyKeyServer.exe is installed and the registry value
  HKLM\SOFTWARE\Yahoo\KeyKey\ServerLocation points to its folder.

Uninstall
---------
Use "Apps & features" / "Add or remove programs" and remove
"Yahoo! KeyKey 2". The uninstaller removes the registration, certificate,
and input profile. If a running app still holds the DLL, the file is removed
on the next Windows restart.

Limitations
-----------
- x64 only.
- Reuses the legacy out-of-process KeyKey server and its WinForms UI.
- The local test certificate is intended for local installation only. Use a
  real code-signing certificate for public distribution.
