Yahoo! KeyKey TSF bridge 1.0.3 (x64)
====================================

Requirements
------------
- Windows 10/11 x64
- Administrator access for installation

Install with the EXE installer (recommended)
-------------------------------------------
1. Run KeyKeyTSF-1.0.3-x64-Setup.exe.
2. Approve the UAC prompt.
3. Follow the English wizard. The default folder is:
   C:\Program Files\Yahoo! KeyKey TSF
4. Restart WhatsApp (or any app that was already open).
5. Focus a text box and press Win+Space until
   "Yahoo! KeyKey (TSF)" is selected.

If Yahoo! KeyKey 1.1.2535 is not installed, the installer installs the bundled
original KeyKey engine silently first. If KeyKey is already installed, it is
left untouched.

Install from the ZIP (advanced)
-------------------------------
1. Extract this ZIP to a normal writable folder.
2. Open a PowerShell window in this folder and run:

       Set-ExecutionPolicy -Scope Process Bypass -Force
       .\install.ps1

   If PowerShell is not elevated, the installer automatically relaunches an
   elevated Windows PowerShell window. Approve the UAC prompt.

3. Restart WhatsApp (or any app that was already open).
4. Focus a text box and press Win+Space until
   "Yahoo! KeyKey (TSF)" is selected.

The ZIP installer creates a local code-signing certificate, trusts it on this
machine, signs the DLL, installs it under C:\Program Files\KeyKeyTSF, and
registers the TSF profile. It also adds the Traditional Chinese input profile
to the current user. Yahoo! KeyKey must already be installed.

Troubleshooting
---------------
- Set KEYKEY_TSF_DEBUG=1 for the target app, restart it, and read
  %TEMP%\KeyKeyTSF.log.
- Restart ctfmon.exe / TextInputHost.exe (elevated) if the profile does not
  appear.
- Make sure KeyKeyServer.exe is installed and the registry value
  HKLM\SOFTWARE\Yahoo\KeyKey\ServerLocation points to its folder.

Uninstall
---------
Use "Apps & features" / "Add or remove programs" and remove
"Yahoo! KeyKey TSF". The uninstaller removes the TSF registration, certificate,
and input profile. If a running app still holds a TSF DLL, the file is removed
on the next Windows restart.

For the ZIP installation, run uninstall.ps1 from an elevated PowerShell.

Limitations
-----------
- x64 only.
- Reuses the legacy out-of-process KeyKey server and its WinForms UI.
- The local test certificate is intended for local installation only. Use a
  real code-signing certificate for public distribution.
